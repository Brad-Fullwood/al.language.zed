## Findings

### [R14-RT-1] the byte budget counts what collections hold, so a text passed down a recursion or copied into records takes memory past it
- where: crates/al-runtime/src/interpreter/value.rs:676-693 (`MAX_HELD_BYTES` counts List and Dictionary elements, array elements, TextBuilders and JSON nodes, and nothing else), against crates/al-runtime/src/interpreter/dispatch/mod.rs:85 (`MAX_RECURSION_DEPTH`, 512, each level binding its own copy of a Text parameter) and crates/al-runtime/src/interpreter/records/crud.rs:783 (`Insert` stores the record's field values, which no budget counts), and the SEC7-3 scenario, which names "a record inserted in a loop" among the shapes
- severity: low
- scenario: SEC7-3 with the copies kept where the fix does not count them. `T := 'x'; for I := 1 to 25 do T := T + T; exit(Deep(T, 16))` with `local procedure Deep(T: Text; N: Integer): Integer` calling itself with `N - 1` returns 33554432 in 1.4 s with the test process's peak resident size at 1,162 MiB, past the 256 MiB budget with no error. At the recursion cap and the 64 MiB text cap the same shape asks for about 64 GiB, and the measured rate reaches the 30 s deadline at about 24 GiB. Record fields check their declared length, so the record route is slower: a table with ten `Text[2048]` fields and 20,000 rows inserted in a loop holds 419 MiB after 11 s in the debug build with no error. Confirmed with `r14_scratch_budget_stack` and `r14_scratch_budget_wide_records` in records_tests.rs.
- fix: charge a Text, Code or Blob parameter and local variable against the budget when it is bound and give it back when its frame ends, or bound the bytes a call frame's variables hold. Charge the text bytes of a record's fields on `Insert` and `Modify` and give them back on `Delete` and `DeleteAll`. Pin the recursion shape against the budget error.
- status: open

### [R14-TRUST-1] a project whose settings name a system .NET folder as a probing path is hashed in full on each decision, and past 256 MiB it cannot be trusted, with advice that does not fit
- where: crates/al-project/src/trust.rs:1618 (`al.assemblyProbingPaths` goes to `with_path_contents` with `Outside::Hashed`, the SEC7-4 fix, so an absolute probing path outside the project is hashed as a tree), :1240 (`MAX_HASHED_BYTES`, 256 MiB for one tree), :336-341 (`grant_refusal` for a path the record cannot hash: "Replace the link with the file it names, or move the file into a directory of its own"), against Docs/features/project-trust.md:204 (the way out, writing the path in `~/.config/al-lsp/settings.json`, which the refusal does not name)
- severity: low
- scenario: a project whose `.vscode/settings.json` has `"al.assemblyProbingPaths": ["./.netpackages", "<dotnet folder>"]`, the shape on-premises projects that use .NET interop write with the Windows assembly folder. With `/usr/share/dotnet/shared` (164 MiB on this machine) `grant` takes 2.5 s, and each later decision reads the 164 MiB again to compare. With an outside folder over the budget (a 2 MiB file under a 1 MiB test budget) `grant` refuses with `<dir>: <dir> holds more than 1 MiB (from .vscode/settings.json). ... Replace the link with the file it names, or move the file into a directory of its own, then run al-explorer trust again.` The folder holds no link, and moving system files is not an answer, so the user is left with a project that stays untrusted, and the path appears twice in the first sentence. Before SEC7-4 the path was recorded as text and the grant went through. The size of `C:\Windows\Microsoft.NET\assembly` on a Business Central developer machine is [UNVERIFIED: `du` of that folder on a Windows machine would give it], and a second .NET version under `/usr/share/dotnet/shared` passes 256 MiB here. Confirmed with `r14_scratch_a_system_probing_path_in_the_repository` in trust_tests.rs.
- fix: when the path the record cannot hash is outside the project, say so in the refusal and name the way out: write the path in `~/.config/al-lsp/settings.json`, which is the user's and stays out of the record, and remove it from the project's settings. Print the path once. Pin the refusal text for an outside probing path over the budget.
- status: open
