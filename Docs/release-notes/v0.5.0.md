# AL Language for Zed v0.5.0

## Install

- Install from source. The extension is not in Zed's extension gallery yet.
  1. `git clone --recurse-submodules https://github.com/Brad-Fullwood/al.language.zed`
  2. In the clone, run `make install` (Linux and macOS). It builds an optimised `al-lsp` and
     `al-explorer` and copies them into the extension's work directory and `~/.local/bin`.
  3. In Zed, run `zed: install dev extension` and choose the clone.
- On Windows, skip step 2. Once this release exists, the dev extension downloads `al-lsp` from it.
- After a pull, run `make install` and `zed: install dev extension` again. When `al-lsp` and the
  extension come from different commits, the language server shows a warning that names both
  steps.
- `make install` stages each copy and checks that the new `al-lsp` runs before it replaces the
  old files. `make watch` rebuilds and copies through `make install-lsp`.
- The extension checks every file of a downloaded release against `binary-checksums.txt`
  before it marks a program executable, and extracts into a staging directory first. A release
  without that file, or without entries for the bridge files, is refused.

## Project trust

- The trust record now covers the `dotnetPath` of the `al-tools` context server. A trusted
  project whose `.zed/settings.json` sets that value asks for trust once more after the update.
  Run `al-explorer trust` in the project again.
- `al.dotnetPath` that names a `dotnet` inside the project is not used by the language server or
  the debug adapter. Keep a pinned SDK outside the project.

## Editor

- Project diagnostics are sent under their own lock, so an edit does not wait for a project
  pass.
- Code action, rename and Format File edits carry the buffer version when the client supports
  it.
- A quick fix request no longer runs the source actions it did not ask for.
- `al.enableCodeActions: false` removes every editor action.
- A rename local to a procedure leaves `Record.Member` of the same name alone.
- A range format edit no longer adds an empty line.
- An `.alformat.json` over 64 KiB, or one that is not a regular file, gives a configuration
  error.
- Files parse with the `preprocessorSymbols` of their own app.
- An unreadable symbol package or source file is skipped with a warning, instead of failing the
  start or the scan.

## Debugger and snapshots

- Cloud debug sessions bind to the web client session through the `HubConnected` message and the
  gateway affinity cookie, as Microsoft's client does. The CLI and MCP queue a breakpoint set
  before the bind and send it once the bind happens.
- Breakpoint ids sent to the editor are small numbers counted by the adapter.
- Snapshot finish stores the zip in the session store before the server call. When the local
  save fails, the zip stays there. A finish response that is not a zip is an error.
- Sampling profiles read their times from `timeDeltas`, as Microsoft's AL extension does.
- The snapshot, capture, negotiate and environment version clients follow no redirect.
- A cached token is used only for the client id, scope and endpoint it was issued for. Expect at
  most one new sign-in.
- On Linux with no display, sign-in goes straight to the device code. `al.entraIdAuthentication`
  is read from the workspace settings.

## MCP and the command line

- For a customer tenant, each CLI or MCP request needs the purpose typed on that request.
- MCP result schemas match the results, `sessionId` -1 is accepted, and at most 8 tool calls run
  at once.
- A daemon write refuses when the file changed on disk after the daemon read it.
- A search or event trace cut at its budget returns `complete: false`, and `al-explorer` prints
  the cut.
- Output files are written to a new file beside the target and renamed over it.

## Claude Code plugin

- Automatic download of `al-lsp` and `al-explorer` is off in this plugin version. Install them
  from source with `make install`. The plugin finds them in `$AL_BIN_DIR`, `$CARGO_TARGET_DIR`,
  the clone's `target/editor`, `target/release` or `target/debug`, or on `PATH`.

## Local build and test

- A build whose package is missing fails.
- Native test runtime: FlowFields read zero until `CalcFields`, `InitValue` applies,
  `asserterror` rolls back record writes, `0T` differs from midnight, `0D` formats as empty, each
  codeunit instance keeps its own globals, and an unused handler fails the test.
- A mutation run that is stopped restores the original source.
- XLIFF files are read with an XML reader, and a malformed file is refused.
