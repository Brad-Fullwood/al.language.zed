# T-013: Convert al-syntax recursive traversals to iterative
## Status: COMPLETED
## Changes
- File: `crates/al-syntax/src/tokens.rs`, `crates/al-syntax/src/complexity.rs`, `crates/al-syntax/src/symbols.rs`
- What: Converted `collect_tokens`, `collect_procedure_complexity`, `count_cyclomatic_decisions`, `compute_cognitive`, and `collect_var_symbols_recursive` from recursive to iterative traversal using an explicit `Vec<Node>` stack.
## Validation
- Compiles: YES
- Tests: PASS (943 tests, 1 pre-existing failure)
## Justification
Deeply nested AL objects could exhaust the call stack in recursive traversals. Iterative traversal with an explicit stack is safe for arbitrarily deep ASTs and follows the established project pattern.
