# T-015: Convert al-symbols namespace recursion to iterative
## Status: COMPLETED
## Changes
- File: `crates/al-symbols/src/model.rs`
- What: Converted `collect_entries_recursive` (which recurses into nested BC v20+ namespaces without depth limit) to iterative traversal using an explicit work queue.
## Validation
- Compiles: YES
- Tests: PASS (943 tests, 1 pre-existing failure)
## Justification
Adversarial or malformed `.app` files with deeply nested namespaces could overflow the stack. An iterative approach is safe for any namespace depth and eliminates the unbounded recursion.
