# T-031: Build O(1) HashSet/HashMap indexes for LanguageData lookups
## Status: COMPLETED
## Changes
- File: `crates/al-syntax/src/language_data.rs`
- What: Added `LazyLock<HashSet>` and `LazyLock<HashMap>` indexes that are built once at first access, replacing the O(n) linear scans in `is_keyword`, `builtin_function_by_name`, and `object_type_by_keyword`.
## Validation
- Compiles: YES
- Tests: PASS (943 tests, 1 pre-existing failure)
## Justification
These functions are called on every token during completion, hover, and formatting; converting from O(n) scan to O(1) hash lookup eliminates measurable latency on large AL files.
