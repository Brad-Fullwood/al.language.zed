# T-020b: Replace hardcoded `permission_for_kind` match with LanguageData
## Status: COMPLETED
## Changes
- File: `crates/al-core/src/permissions.rs`, `tree-sitter-al/data/object_types.json`
- What: Added `permission_type` and `permission_value` fields to `object_types.json`; replaced the hardcoded `permission_for_kind` match expression with a `LanguageData` lookup.
