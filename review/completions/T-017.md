# T-017: Fix UTF-16 conversion in al-core inlay_hints and resolution
## Status: COMPLETED
## Changes
- File: `crates/al-core/src/queries/inlay_hints.rs`, `crates/al-core/src/resolution.rs`
- What: Replaced `node.start_position().column` (byte offset) used as `Position.character` (UTF-16) with proper UTF-16 counting; replaced `line.find()` byte index with correct UTF-16 column conversion.
## Validation
- Compiles: YES
- Tests: PASS (943 tests, 1 pre-existing failure)
## Justification
LSP positions must be UTF-16 code units; using raw byte offsets silently produces wrong positions for any AL file containing non-ASCII characters (e.g. accented identifiers, string literals).
