# T-023: Fix DAP session mutex contention blocking event forwarding
## Status: COMPLETED
## Changes
- File: `crates/al-dap-client/src/native_dap.rs`
- What: Cloned the required data from the session guard and dropped it before awaiting `invoke()`, so the mutex is no longer held for up to 60s while waiting for the BC debugger to respond.
## Validation
- Compiles: YES
- Tests: PASS (943 tests, 1 pre-existing failure)
## Justification
Holding the session mutex across a long `invoke()` call starved the background event-forwarding task, causing stopped/breakpoint events to be delayed until the current command completed.
