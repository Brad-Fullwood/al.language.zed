# T-006: Fix al-explorer terminal restore on panic

## Status: COMPLETED

## Task
Install a `std::panic::set_hook` in al-explorer's `main()` that restores terminal state before printing the panic message.

## Changes Made
- **File:** `crates/al-explorer/src/main.rs`
- **Added at the start of `main()`** (before `enable_raw_mode()`):
  ```rust
  let original_hook = std::panic::take_hook();
  std::panic::set_hook(Box::new(move |info| {
      let _ = crossterm::terminal::disable_raw_mode();
      let _ = crossterm::execute!(std::io::stderr(), crossterm::terminal::LeaveAlternateScreen);
      original_hook(info);
  }));
  ```

## Validation
- Compilation: `cargo check -p al-explorer` — PASS
- Hook installed before `enable_raw_mode()` — correct ordering
- Uses `let _ =` for both restore calls — appropriate since we're in a panic handler
- Calls `original_hook(info)` to preserve the default panic output

## Justification
Without this hook, any panic during rendering (e.g., from an unexpected ratatui error) leaves the terminal in raw mode with the alternate screen active, making the shell completely unusable.
