# T-029: Fix `collect_dataitem_vars` zero-byte ranges
## Status: COMPLETED
## Changes
- File: `crates/al-syntax/src/type_resolver.rs`
- What: Fixed `collect_dataitem_vars` to compute actual `start_byte`/`end_byte` from the node's line and column information instead of emitting synthetic `VariableDecl` entries with both fields set to `0`.
## Validation
- Compiles: YES
- Tests: PASS (943 tests, 1 pre-existing failure)
## Justification
Zero-byte ranges caused hover, go-to-definition, and rename to silently fail for dataitem variables because range containment checks always returned false for a zero-length range.
