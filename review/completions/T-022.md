# T-022: Propagate step/continue errors to Zed instead of silent success
## Status: COMPLETED
## Changes
- File: `crates/al-dap-client/src/native_dap.rs`
- What: Replaced `let _ = invoke()` with proper error checking in `continue`, `next`, `stepIn`, and `stepOut` handlers; failure now returns a DAP error response instead of `"success": true`.
## Validation
- Compiles: YES
- Tests: PASS (943 tests, 1 pre-existing failure)
## Justification
Silently returning success on a failed step command left Zed's debugger UI in an inconsistent state with no indication of the failure; propagating the error lets Zed display it correctly.
