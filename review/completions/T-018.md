# T-018: Fix UTF-16 conversion in al-syntax formatting
## Status: COMPLETED
## Changes
- File: `crates/al-syntax/src/formatting.rs`
- What: Fixed `format_range` which used `l.len()` (byte length) as the LSP end-character field; replaced with `byte_col_to_utf16_col` to produce the correct UTF-16 column.
## Validation
- Compiles: YES
- Tests: PASS (943 tests, 1 pre-existing failure)
## Justification
Range formatting on files with non-ASCII content would produce mis-aligned edit ranges in Zed because byte length and UTF-16 length diverge for multi-byte characters.
