# T-037: Fix al-symbols `getrandom().expect()` panic in library code
## Status: COMPLETED
## Changes
- File: `crates/al-symbols/src/oauth.rs`
- What: Changed `random_bytes` from panicking with `.expect()` on `getrandom` failure to returning `Result` and propagating the error to the caller.
## Validation
- Compiles: YES
- Tests: PASS (943 tests, 1 pre-existing failure)
## Justification
Library code must never panic; a system-level RNG failure (e.g. restricted sandbox) would crash the entire language server instead of returning a graceful error to the OAuth flow.
