# T-008c: Fix `unreachable!()` in test_diagnostics.rs

## Status: COMPLETED

## Task
Replace `TestStatus::Pass => unreachable!()` with `continue` in production library code.

## Changes Made
- **File:** `crates/al-core/src/queries/test_diagnostics.rs`
- **Line 106:** Changed `TestStatus::Pass => unreachable!()` to `TestStatus::Pass => continue`

## Validation
- Compilation: `cargo check -p al-core` — PASS
- The function `results_to_diagnostics` filters for non-pass results, but the match arm handles Pass defensively
- `continue` skips generating a diagnostic for passing tests — correct behavior
- No other code paths affected

## Justification
Production library code must not panic. While the `Pass` arm shouldn't be reached in normal operation (the caller pre-filters), defensive code is preferable to `unreachable!()`. If a `Pass` result does reach this code due to a caller bug, silently skipping it is far better than crashing the language server.
