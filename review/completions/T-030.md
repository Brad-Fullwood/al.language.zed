# T-030: Fix `sort_members` to recognize all procedure visibility modifiers
## Status: COMPLETED
## Changes
- File: `crates/al-syntax/src/sort.rs`
- What: Extended `is_member_keyword` to recognize `internal procedure`, `protected procedure`, and `protected local procedure` in addition to the previously handled `procedure` and `local procedure`.
## Validation
- Compiles: YES
- Tests: PASS (943 tests, 1 pre-existing failure)
## Justification
Files using BC v21+ visibility modifiers were silently corrupted by `sort_members` because unrecognized keywords broke the member boundary detection, causing wrong blocks to be reordered.
